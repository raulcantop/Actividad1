# Proyecto de Despliegue de Aplicaciones Web
Este repositorio contiene las prácticas correspondientes al módulo de **Despliegue de Aplicaciones Web**.

## Contenido del Proyecto
- Control de versiones con Git y gestión remota en GitHub.
- Automatización de ramas y estrategias de fusión (*merge*).
- Configuración de exclusiones mediante `.gitignore`.
